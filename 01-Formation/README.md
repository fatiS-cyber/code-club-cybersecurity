# Formation

This folder contains the learning materials used to build cybersecurity knowledge.

The formation will progressively cover:

* Computer fundamentals
* Operating systems and Linux
* Networking
* Python for cybersecurity
* Cybersecurity fundamentals
* Cryptography
* Web security
* Ethical hacking
* Capture The Flag (CTF)
* Cybersecurity specializations

The content is intended to support both the preparation of cellule members and the learning of students.
